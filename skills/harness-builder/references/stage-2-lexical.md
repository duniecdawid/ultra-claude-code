# Stage 2 — Lexical

Scope: stage 2 of the build workflow — the hand lexical pass on structurally-settled text. The only stage that touches descriptions.

## Prepare

1. **Bodies and prose:** apply the house style in `efficient-communication.md` by hand. This pass is judgment — wording, altitude, modality; the mechanical engine pass comes at stage 3 and is not a substitute for it.
2. **Descriptions (skill and agent):** compress against `description-writing.md` — budgets, key-term precedence (key terms win over budget on conflict; an overshoot is stated, never hidden), sibling distinguishability. Descriptions **never reach the engine**: it splits YAML frontmatter off and re-prepends it verbatim ([MEASURED 2026-07-27]), and forced through as prose it trades routing key terms for a few percent.
3. Respect the payload-zone inventory from stage 1 — those spans stay byte-identical.
4. Record the proposed lexical edits in the plan file (before → after per edit, or full revised text for short artifacts).

## Discuss — exit gate

Same rule as stage 1: explicit confirmation only ("lexical settled", "go to compression"); conversational acknowledgements don't advance the stage.
